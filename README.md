## O projeto

Site de apresentação da Emcomp, empresa júnior de Computação do IF Sudeste MG, campus Rio Pomba. O repositório reúne páginas e recursos de interface construídos com **HTML, CSS e JavaScript**.

## Conteúdo

- Página inicial com apresentação da marca.
- Seções de serviços, diferenciais e informações institucionais.
- Modal com formulário de contato integrado ao FormSubmit.
- Página de agradecimento após o envio.

## Executar localmente

Clone o repositório e abra `index.html` no navegador, ou sirva os arquivos com um servidor estático.

```bash
git clone https://github.com/JoaoMFserafim/Site-emcomp.git
cd Site-emcomp
python3 -m http.server 8000
```

Acesse `http://localhost:8000`. O comando de servidor requer Python 3.


## Observações

O formulário usa um serviço externo e possui um destinatário configurado no HTML. Para testar uma cópia, ajuste essa configuração antes de enviar mensagens. Alguns contatos exibidos na página estão identificados como fictícios.
